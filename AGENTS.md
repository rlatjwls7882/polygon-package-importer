# Product terminology

This extension imports Polygon-format problem-package ZIPs into Codeforces Polygon,
regardless of which tool exported the ZIP.

Use Polygon package terminology in documentation, release notes, Store listings,
UI messages, and test or benchmark descriptions. Keep exporting judge names out of
that public product text. Apply this rule to GitHub release and PR descriptions too.

Preserve exact input-format identifiers required to read existing archives, along
with their compatibility fixtures. Terminology edits must retain those import checks.

Run the validation commands in CONTRIBUTING.md before submitting changes.
