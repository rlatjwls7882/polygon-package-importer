# Polygon ZIP Uploader

Upload a Polygon problem-package ZIP to [Codeforces Polygon](https://polygon.codeforces.com).

[Install from Chrome Web Store](https://chromewebstore.google.com/detail/polygon-zip-uploader/fhlocfeafcanblbeppffhdilbkblmdcn)

1. Create an API Key and Secret in [Polygon settings](https://polygon.codeforces.com/settings).
2. Open the extension and save the keys.
3. Select a ZIP containing `problem.xml`, then choose a new or existing problem.
4. Click **Upload to Polygon**.

Uploads continue after the popup closes. Failed jobs can be retried.

**Before replacing a problem:** Back it up. Files, tests, and statement attachments missing from the ZIP may be deleted. Only the default `tests` testset is supported; new binary files and statement images cannot be uploaded. ZIP limit: 100 MB.
