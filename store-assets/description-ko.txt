컴퓨터에 저장된 문제 패키지 ZIP을 Codeforces Polygon에 업로드하는 Chrome 확장 프로그램입니다. 새 문제를 만들거나 기존 문제를 갱신할 수 있습니다.

사용 방법
1. 확장 프로그램 팝업에서 Polygon API Key와 Secret을 등록합니다.
2. problem.xml이 포함된 ZIP 파일을 선택합니다.
3. 새 문제 또는 기존 문제를 선택하고 업로드합니다.

기본 tests 테스트셋만 지원합니다. 기존 문제를 갱신하면 ZIP에 없는 파일이나 테스트가 삭제될 수 있으며, 자동 백업은 제공하지 않습니다.

Codeforces 공식 확장 프로그램이 아닙니다.
