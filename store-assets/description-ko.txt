Polygon ZIP Uploader는 컴퓨터에 저장된 Polygon 문제 패키지 ZIP의 내용을 Codeforces Polygon으로 가져오는 Chrome 확장 프로그램입니다. ZIP을 로컬에서 분석한 뒤 Polygon API로 새 문제를 생성하거나 기존 문제를 갱신합니다.

주요 기능
- ZIP에서 문제 지문, 소스 코드, 솔루션, 테스트 및 기본 설정 가져오기
- 새 문제 생성 또는 수정 권한이 있는 기존 문제 갱신
- 기존 문제와 비교해 내용이 같은 파일과 테스트는 재전송 생략
- 팝업을 닫은 뒤에도 업로드 진행 및 중단된 작업 재시도

사용 방법
1. 확장 프로그램 팝업에서 Polygon API Key와 Secret을 등록합니다. 등록된 경우 바로 ZIP 업로드 화면이 나타납니다.
2. 컴퓨터에서 problem.xml이 포함된 문제 패키지 ZIP을 선택합니다.
3. 새 문제 또는 기존 문제를 선택하고 업로드합니다.
4. Polygon에서 가져온 파일과 컴파일러 설정을 확인합니다.

알아두기
- Codeforces Polygon 계정과 API 인증 정보가 필요합니다.
- 단일 문제 패키지의 기본 tests 테스트셋을 지원합니다. 일부 특수 설정이나 컴파일러 버전은 그대로 복원되지 않을 수 있습니다.
- 기존 문제 갱신 시 ZIP에 없는 항목이 삭제될 수 있습니다. 자동 백업이나 롤백은 제공하지 않습니다.

이 확장 프로그램은 Codeforces에서 제작하거나 공식 승인한 제품이 아닙니다.
