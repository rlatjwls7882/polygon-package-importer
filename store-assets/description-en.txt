Upload a local problem-package ZIP to Codeforces Polygon to create a new problem or update an existing one.

How to use
1. Open the extension and enter your Polygon API key and secret.
2. Select a ZIP containing problem.xml.
3. Choose a new or existing problem and start the upload.

Only the default tests test set is supported. Updating an existing problem may delete files or tests missing from the ZIP. No automatic backup is provided.

This extension is not affiliated with Codeforces.
